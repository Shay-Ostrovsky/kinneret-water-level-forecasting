// Overview

About the Project

The Sea of Galilee (Kinneret) is Israel's largest freshwater reservoir and a critical national resource. This project builds a production-grade forecasting system that ingests live measurement data from Israel's open government API and predicts future water levels using a suite of ML models.

The core challenge was long-horizon forecasting without look-ahead bias — solved through a recursive multi-step strategy where each prediction feeds back into the model as input for subsequent steps, faithfully mimicking real-world deployment conditions.

// Methodology

Key Techniques

🔁
Recursive Multi-Step Forecasting Each predicted value is fed back as input for the next time step, enabling genuine long-horizon forecasting without relying on future ground-truth data. Generates 90-day forward projections.
📊
Time-Series Cross-Validation (8 Folds) Applied TimeSeriesSplit throughout the entire pipeline — from model selection to Optuna hyperparameter tuning — strictly preserving temporal order and eliminating data leakage.
⚙️
Automated Hyperparameter Optimization Leveraged Optuna to systematically search the hyperparameter space for both XGBoost and LightGBM, using recursive RMSE on time-series CV folds as the objective function.
🛠️
Temporal Feature Engineering Engineered lag features (7, 30, 365 days), rolling statistics (mean, min, max, std) over 7/30/90-day windows, and cyclical sine/cosine encodings for seasonal patterns.
🔍
Feature Importance Analysis Revealed that short-term rolling statistics (7-day max/mean) dominate predictive signal — confirming strong short-term momentum in water level dynamics.
